# سایت ISLAMIC REPUBLIC OF IRAN – تبدیل عکس به QR Code

این پروژه یک سایت آماده Node.js است: مدیر با رمز وارد می‌شود، عکس و سریال دلخواه را ثبت می‌کند، QR سیاه‌وسفید ساخته می‌شود و اسکن آن عکس را باز می‌کند. هر عکس دقیقاً ۱۴ روز پس از زمان ثبت منقضی می‌شود. فایل عکس در Cloudinary و اطلاعات آن در MongoDB نگهداری می‌شود.

## نکته مهم
این فایل‌ها خودِ سایت هستند، نه آدرس اینترنتیِ منتشرشده. برای داشتن لینک عمومی باید پروژه روی هاست اجرا شود و سرویس‌های ذخیره‌سازی زیر به آن متصل شوند. من نمی‌توانم بدون ورود و تأیید شما در حساب‌های میزبانی، سایت را از طرف شما منتشر کنم.

## پیش‌نیازهای انتشار
۱. یک حساب Cloudinary برای نگهداری عکس‌ها بسازید و مقادیر Cloud name، API Key و API Secret را بردارید.
۲. یک دیتابیس MongoDB Atlas بسازید و آدرس اتصال (MONGODB_URI) را بردارید. دسترسی شبکه دیتابیس باید برای هاست مجاز باشد.
۳. پروژه را در یک میزبان Node.js مانند Render منتشر کنید؛ Build Command برابر `npm install` و Start Command برابر `npm start` باشد.
۴. در تنظیمات Environment میزبان، این متغیرها را ثبت کنید:

- `CLOUDINARY_CLOUD_NAME` = نام Cloudinary
- `CLOUDINARY_API_KEY` = کلید API
- `CLOUDINARY_API_SECRET` = رمز API
- `MONGODB_URI` = آدرس اتصال MongoDB
- `SESSION_SECRET` = یک رشته تصادفی و طولانی که فقط برای نشست‌های ورود استفاده می‌شود
- `BASE_URL` = آدرس نهایی سایت، مثل `https://your-site.onrender.com` (بدون اسلش انتهایی)
- `ADMIN_PASSWORD` = رمز پنل؛ مقدار پیش‌فرض داخل برنامه `IRAN1405@` است. بهتر است در محیط انتشار یک رمز قوی‌تر تعیین کنید.

## راه‌اندازی محلی در ویندوز
Node.js نسخه ۲۰ یا بالاتر را نصب کنید. پوشه پروژه را باز کنید، در نوار آدرس File Explorer بنویسید `cmd` و Enter بزنید. سپس:

```bash
npm install
```

متغیرهای بالا را در محیط سیستم یا فایل `.env` (با نصب dotenv و افزودن `require('dotenv').config()` به ابتدای server.js) قرار دهید؛ سپس:

```bash
npm start
```

برای تست محلی، `BASE_URL` را `http://localhost:3000` بگذارید.

## استفاده
- صفحه اصلی برای جست‌وجوی تصویر با سریال است.
- از تب «مدیریت و آپلود» با رمز مدیر وارد شوید.
- سریال را دستی وارد کنید؛ هر سریال باید یکتا باشد.
- عکس JPEG/PNG/WEBP/GIF حداکثر ۱۰ مگابایت انتخاب و آپلود کنید.
- QR Code را با دکمه دریافت ذخیره یا چاپ کنید.
- اسکن QR Code، صفحه نمایش عکس را باز می‌کند.
- مدیر می‌تواند تصاویر را پیش از موعد هم حذف کند.

## انقضای ۱۴ روزه
زمان انقضا در لحظه آپلود ثبت می‌شود. برنامه در هر ساعت و نیز هنگام درخواست‌های اصلی، تصاویر منقضی‌شده را از Cloudinary و رکوردشان را از MongoDB پاک می‌کند. اگر هاست کاملاً خاموش یا خواب باشد، پاک‌سازی فیزیکی ممکن است تا اولین بیدارشدن سرویس عقب بیفتد؛ با این حال API و صفحه نمایش، عکس منقضی‌شده را بلافاصله نامعتبر می‌دانند.
